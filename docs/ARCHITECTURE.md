# 子平八字

## 📋 架构

浏览器 → Next 同源代理 → FastAPI → 独立 SQLite。

1. POST /api/v1/chart：输入验证、历法、历史时区、真太阳时、候选四柱；不访问AI。
2. POST /api/v1/analyze：读取候选、确定性规则、复核、十二章固定模板、原子冻结。重复确认返回原报告。
3. GET /api/v1/charts/{id}、/analysis、/image.svg：读取同一份结果及附件。
4. POST /api/v1/charts/{id}/revalidate：重新生成候选，旧快照保持不变。
5. POST /api/v1/charts/{id}/ask：验证大师签会话、预占日额度、按主题检索结论和evidence、Magpie解释、核对冻结快照、保存问答。
6. POST /api/v1/charts/{id}/access：首次绑定或重新验证大师签；GET读取授权与问答历史。POST /api/v1/access/report凭原签取回原报告。

## 📋 依赖与锁定

rules → bazi；report → rules/common；ai → LockedChart。bazi/rules/report不导入ai，有AST验收。计算链不读取Key、不访问AI网络。

LockedChart存不可变JSON，读取返回副本；SQLite冻结摘要和触发器禁止UPDATE/DELETE。问答模块只得到分离的数据树，不得到存储句柄。请求前后比较冻结JSON；恶意输出额外命盘字段或未提供证据ID会被拒绝。自由白话解释是展示文本，不写回命盘。

提示词禁止重算、改盘、补算未有结论；若用户质疑结果，引导重新校验。AI输出语言仍属于模型解释，结构锁定不等于能数学证明每句自然语言都完全正确。核心报告始终显示确定性结果和原依据。

## 📋 检索与联网

按问题选取相关字段、对应报告章节和最多40条依据。用神问题取旺衰、用神、月令；流年最多3年及关联大运。方向问题只读取已有方向附录；旧锁定报告无该字段时提示重新校验，不自行补算。

不附带姓名、完整出生时间、出生地或系统诊断。至多3轮历史问答仅供上下文。Magpie原生web_search负责外部查证，显式联网问题要求实际调用工具并返回来源；网页不能成为新的个人命盘结果。不实现可任意读取本地网络的抓取工具。

## 📋 签子与隔离

access.py维护独立access库：随机长签只存SHA256摘要；一签绑定一盘；会话随机令牌、HttpOnly、SameSite=Strict、HTTPS下Secure且无Domain属性。Next仅转发本项目Cookie，不转发NØTA Cookie。

北京时间每日全站和每签各50次上限，原子事务计数；模型请求失败仍计入。每实例一条在途请求，问答记录独立保存。没有公开发签API或账号会员系统。生产建议仅单API进程；多实例须补充分布式在途锁。

## 📋 规则与边界

旺衰结合月令、分层根气、透干、生克泄耗与刑冲；格局保留条件，不自动成从格或合化；喜用分扶抑、调候和通关。人生主题、大运和流年由固定规则与双版本模板解释。

方位附录仅映射已有喜用和地支方位；喜用未定不指定方向，感情支位不能定位配偶。文昌、称骨、鬼谷子和神煞未实现时不输出。

大运三天折一年为近似，8步；流年立春起止、参考年前5年至后10年，交运年分段。未知时辰无虚构时柱，候选逐分钟枚举；交节、均时差、历史时区及起运仍有近似边界。自我复核证明内部一致，不代替权威历书校准。
