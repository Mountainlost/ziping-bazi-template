# 数据来源

## 📋 排盘与历法

- 原仓库：[jinchenma94/bazi-skill](https://github.com/jinchenma94/bazi-skill)。MIT License，保留源代码、LICENSE、原测试和版权声明。
- 固定源版本：`112a5d84cd1a001a0038cafca3be68d93e4c0cc9`。
- 程序直接导入 `pai_pan.py` 的计算、农历换算、节气、干支及大运函数；未修改第三方核心。测试自带 CLI 用例仍沿用原实现。
- 节气采用原项目 Meeus 简式太阳视黄经。年柱按立春、月柱按十二节；精度不等于权威天文历书，临界时刻需交叉核准。
- 农历沿用第三方定朔/定气实现；没有另购官方历书数据库，不宣称跨全部历史日期完成权威校准。

## 📋 地点与时间

- 地点由独立 `/api/v1/locations` 提供本地3066个可匹配地点，31个省级地区、340个城市层级。行政层级来自[modood/Administrative-divisions-of-China](https://github.com/modood/Administrative-divisions-of-China)（WTFPL），坐标来自[GeoNames中国数据](https://download.geonames.org/export/dump/)（CC BY 4.0、WGS84）。快照2026-11-02，源文件SHA256、构建脚本和未匹配名单保存在数据包中。只接受同省市可明确匹配的地名，不按模糊结果猜经度；匹配不到的326条行政记录暂不提供。睢宁县现用117.85877/33.93882，代表行政中心，不是医院或街道定位。用户逐级选择地点后自动更新坐标。
- 当前支持中国大陆1901–2098年，UTC+8标准时间，中央经线120°E。UI可选择当年钟表时间，通过 IANA `Asia/Shanghai`（tzdata）还原夏令时；重叠或不存在的钟表时间拒绝猜测。
- 西部地区地方时间须先明确还原为UTC+8，不能把“新疆时间”当作北京标准时间填写。
- 经度修正：`4 × (地理经度 − 120)` 分钟。均时差：[NOAA General Solar Position Calculations](https://gml.noaa.gov/grad/solcalc/solareqns.PDF)，采用 fractional-year Fourier 近似，闰年按366天。它不是太阳黄经；纬度保留供地点核验。
- 日/时柱使用真太阳时，23时换日；年/月柱和起运使用标准时间对应的真实交节瞬间，不能简单将整个出生时间平移后套用北京交节表。
- 真太阳时及节气均有近似误差，不能保证临界分钟或秒的唯一答案。用户时间范围候选按一分钟粒度枚举。

## 📋 传统解释

- 自有规则库 `ziping-conservative-1.0`，公开实施逻辑见 ARCHITECTURE.md；没有把原第三方 Skill 的 AI 命理分析当作运算模块。
- 十神与藏干复用基础表，旺衰、格局、扶抑/调候/通关、大运流年主题均由本地规则返回 conclusion / stability / evidence。
- 格局仅给候选；调候尚未覆盖每个日干专属的经典细则，四季土月未按司令天数细分，合化不自动成立；从格保留条件。
- 这些属于传统文化解释体系，不是经科学验证的预测模型。固定模板提供阅读线索，不提供医学诊断、收益预测或必然婚恋事件。

## 📋 可选 AI

- 仅明确设置MAGPIE_CONFIG_FILE才启用用户授权网关，默认DeferredProvider；旧OpenAI环境变量不激活问答。实际网关与原生web_search已在电脑 A验证。
- AI只读相关锁定结论与相同evidence，生成白话解释及查证来源；不参与排盘、命局判断、固定报告或复核。联网结果不能作为新的个人命盘事实。

## 📋 方位附录

五行映射使用用户确认的五行方位表，输入仅为已确定的喜用。地支方位依据《三命通会》卷三的方隅记述及国立台北艺术大学《文资学报》中的二十四山位置说明，资料链接保存在directions.references。该附录仅解释传统方位对应，不能据此推断配偶住址或实际相遇位置；不是综合桃花、夫妻星的地理预测。未实现文昌、称骨、鬼谷子或神煞不输出相关个人结论。

## 📋 子平解盘原典对照

- [《子平真诠》第二卷影印本](https://commons.wikimedia.org/wiki/File:NLC416-13jh002326-46443_淵海子平_子平真詮_第2卷.pdf)的〈论用神〉与〈论用神变化〉用于解释月令、藏干与透干如何参与取格。基础规则从月令本气列候选，尚未覆盖各类格局变化。
- [《穷通宝鉴》〈三冬辛金〉](https://zh.wikisource.org/zh-hant/窮通寶鑑#三冬辛金)仅匹配辛日主、亥月，列出该条对壬、丙与透藏的要求，供寒暖对照。
- [《三命通会》卷九〈六辛日甲午时断〉](https://zh.wikisource.org/zh-hant/三命通會/卷九#六辛日甲午時斷)仅匹配辛亥日、甲午时且年、月支均在亥子范围内的命盘。作为日时条文解读，结合四柱复核其适用性。

后端按已锁定的四柱选择上述条文，向子平解盘传递简明释义及证据编号。典籍对照独立于基础报告取格和扶抑规则。
